Raw, gzip,

Reusable package ESM, not a closed-world app. Official is the published mobx@7.0.0 ESM. Vite/Terser/Closure run on that same official source. @itslil/mobx is the LilScript production artifact.

Lane Raw gzip-9 Brotli-11 vs official

Why Closure ADVANCED is still smaller. This package compiles realistic-performance-first with property mangling off: it is a reusable MobX ABI, and tests/JS consumers read real keys. The current source is also open-world JsValue bags (value_, observers_), so LilScript’s owned-field mangler would not rename those keys even if the flag were on. Closure ADVANCED of official is a size-only lane and is not the throughput baseline.
